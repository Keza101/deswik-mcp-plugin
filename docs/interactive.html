Recommended pilot

A narrow integration with a clear acceptance path.

  1. Generate a three-stage map: Inspect stope, Preview rings, Approve write.
  2. Keep calculations deterministic outside CAD.
  3. Write proposed geometry to a temporary preview layer.
  4. Commit native UGDrillHole entities only after confirmation.
  5. Record source handles, parameters, warnings, created handles, versions, and disposition.
Boundary that stays manualBinary round-trip validation cannot prove a node runs correctly. Open every generated map in Deswik.CAD and click each changed node before production use.

System design

One workflow, two execution environments

Process-map logic is packaged and inspectable. Live CAD calls stay inside the Deswik add-in and are marshalled onto the CAD UI thread.
